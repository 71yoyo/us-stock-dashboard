# 📈 US Stock Pro - 미국 주식 대시보드 (Mobile & Desktop)

나만의 비공개 미국 주식 포트폴리오 관리 및 실시간 캔들 차트 분석 대시보드입니다.

## ✨ 주요 기능
1. **🔒 나만의 보안 PIN 잠금**: 4자리 비밀번호(기본: 1234)로 외부 열람 차단
2. **📱 모바일 & PC 반응형 UI**: 스마트폰 홈 화면 추가(PWA) 지원 및 터치 제스처 최적화
3. **📊 인터랙티브 캔들 차트**: TradingView Lightweight Charts 탑재 (이동평균선 MA20, MA60, 거래량)
4. **💼 내 포트폴리오 관리**: 매수가, 보유수량, 실시간 평가손익 및 수익률 자동 계산 ($ 및 ₩ 원화 환산)
5. **⭐ 관심종목 (Watchlist)**: 주요 지수 및 개별 종목 시세 트래킹
6. **💾 안전한 백업**: 구글 드라이브 및 JSON 파일 내보내기/불러오기 지원
