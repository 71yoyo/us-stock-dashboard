# Williams %R 전략 메모

이 문서는 US Stock Pro의 Williams %R(14) 전략을 나중에 다시 검토하고 수정하기 위한 기록이다. 사용자가 대화에서 제안한 판단 원칙과 현재 구현 상태를 구분한다. 책에서 얻은 통찰은 아직 전달받지 않았으므로 아래의 연구 메모에 추후 추가한다.

- 최초 정리: 2026-09-23
- 적용 범위: 관심종목 전체, 일봉 종가 기준
- 상태: 로컬 작업 기록. GitHub·Cloudflare 배포 여부는 별도로 확인한다.
- 이 문서의 수치·종목 예시는 특정 날짜의 검증 사례이며 실시간 값이 아니다.

## 1. 목적과 기본 원칙

- Williams %R은 최근 14개 거래일의 고가·저가 범위에서 종가가 어디에 있는지를 나타낸다. 범위는 `-100`에서 `0`이다.
- `-80` 이하는 과매도, `-20` 이상은 과매수, 그 사이는 중립으로 본다. 과매도·과매수만으로 즉시 매매를 확정하지 않고 방향 전환과 기준선 접촉을 구분한다.
- 신호는 모든 종목에 같은 규칙으로 적용한다. 하루의 확정 일봉이 추가되면 다시 계산하며, 장중 위젯 움직임을 확정 신호처럼 취급하지 않는다.
- 이 지표는 판단 보조 도구다. 추세가 강하면 극단 구간에 오래 머물 수 있고, 신호는 수익을 보장하지 않는다.

## 2. 현재 합의한 화면 신호

| 현재 구간·변화 | 표시 | 의미 |
| --- | --- | --- |
| `%R <= -80`, 전일보다 상승 | `매수 검토` | 과매도 구간에서 하락을 멈추고 반등 중 |
| `%R <= -80`, 상승하지 않음 | `매수 신호 유지` | 과매도 구간에 계속 있음. 새 매수 확정 신호는 아님 |
| 전일 `%R < -80`, 오늘 `%R >= -80`이고 상승, 종가도 상승 | `매수 신호` | 과매도 기준선을 위로 터치·돌파한 날 |
| `%R >= -20`, 전일보다 하락 | `매도 검토` | 과매수 구간에서 상승을 멈추고 하락 중 |
| `%R >= -20`, 하락하지 않음 | `매도 신호 유지` | 과매수 구간에 계속 있음. 새 매도 확정 신호는 아님 |
| 전일 `%R > -20`, 오늘 `%R <= -20`이고 하락, 종가도 하락 | `매도 신호` | 과매수 기준선을 아래로 터치·이탈한 날 |
| `-80 < %R < -20`, 전일보다 상승 | `관찰-상승중` | 중립 구간의 상승 흐름 |
| `-80 < %R < -20`, 전일보다 하락 | `관찰-하락중` | 중립 구간의 하락 흐름 |
| `-80 < %R < -20`, 전일과 동일 | `관찰-보합` | 중립 구간의 방향 없음 |

`매수/매도 신호`는 기준선에 닿거나 넘어선 해당 일봉에서 표시한다. 이후 중립 구간에 있으면 직전 신호를 무기한 고정하지 않고 `관찰-상승중/하락중/보합`으로 표시한다. 반면 극단 구간에 계속 머무르면 해당 구간의 검토 또는 유지 상태를 매일 다시 보여 준다. 기준선 `-80`·`-20`을 반복해서 넘나드는 경우에도, 새 교차가 없는 날에는 같은 확정 신호를 중복 발행하지 않는다.

## 3. 현재 코드의 추가 확인 규칙

- `%R` 교차만 있고 종가 방향이 반대라면 즉시 `매수 신호` 또는 `매도 신호`로 확정하지 않고 `매수 종가 확인 대기` / `매도 종가 확인 대기`로 표시한다. 이는 14일 최고·최저가 창이 바뀌어 가격과 지표 방향이 달라질 수 있기 때문이다.
- 교차 당일 종가 확인이 없었으나 **다음 일봉에서** 종가 방향이 확인되면 한 차례 지연 확인 신호를 낼 수 있다. 그 뒤에는 현재 구간·방향 규칙으로 돌아간다.
- 14개 이상의 유효한 일봉이 없으면 `%R`과 신호를 계산하지 않고 저장 대기 상태로 둔다. 없는 값을 예시 값으로 대체하지 않는다.
- 14일의 최고가와 최저가가 같으면 0으로 나누지 않도록 `%R = -50`으로 처리한다. 이 예외 처리의 적절성은 추후 검증할 수 있다.

## 4. 화면 표현과 데이터 출처

- 목록의 작은 선은 **최근 13개 저장 일봉의 주가 추이**다. Williams %R 값 자체의 선 그래프가 아니다. 현재 Williams 구간에 따라 선 색만 바뀐다.
- 색: 과매도 `초록`, 중립 `노랑`, 과매수 `빨강`. 극단 구간 선을 조금 더 굵게 그린다. 색만으로 판단하지 않도록 신호 문구와 수치도 함께 표시한다.
- Williams %R 값과 신호는 D1에 저장된 일봉 OHLC에서 계산한다. TradingView 차트 위젯은 별도 표시 기능이며 목록의 확정 신호 출처가 아니다.
- 현재 계산 코드: [`williams-signal.js`](../williams-signal.js). D1 저장 로직: [`worker/src/williams-store.js`](../worker/src/williams-store.js). 회귀 테스트: [`tests/williams-signal.test.js`](../tests/williams-signal.test.js).

## 5. 결정 이력과 검증 예시

1. 최초 아이디어는 스프레드시트의 13일 주가 SPARKLINE을 Williams %R 수준에 따라 초록·노랑·빨강으로 칠하는 것이었다. 현재 목록의 선에도 이 아이디어를 적용했다.
2. 극단 구간 진입만으로 확정 신호를 내지 않고, 구간 안에서의 반전은 `검토`, 기준선 교차는 `신호`로 나누기로 했다.
3. 사용자는 신호가 그날 하루만 보이고 사라지지 않기를 원했다. 후속 논의에서 `신호 유지`는 **극단 구간에 계속 머무는 상태**로 정리했다. 중립 구간에서는 NVDA처럼 `관찰-상승중/하락중`을 표시하도록 변경했다.
4. 사용자 검증 사례: NVDA는 중립 구간에서 `관찰-상승중`, AAPL과 AMZN은 과매수 구간에서 `매도 신호 유지`가 기대 결과였다. 이는 당시 저장 일봉을 기준으로 한 예시이며 가격·지표가 바뀌면 결과도 바뀐다.
5. 단순히 `%R`만 기준선을 넘는 경우를 과대 해석하지 않도록 종가 방향 확인 규칙을 추가했다. 이는 현재 구현 규칙이며, 사용자가 책 내용을 추가하면 재검토할 수 있다.

## 6. 아직 검증·결정할 항목

- `신호 유지`라는 표현이 최초 신호가 발생하지 않았는데도 나타날 수 있다. `과매수/과매도 지속` 등으로 바꿀지 검토한다.
- 14일 기간과 `-80`·`-20` 기준이 모든 종목에 적합한지 과거 데이터로 비교한다.
- 종가 확인과 다음 날 지연 확인이 실제 오신호를 줄이는지 백테스트한다. 거래량·20일 이동평균선 등 추가 확인 조건도 검토 대상이다.
- 액면분할·수정주가, 결측 일봉, 배당락 같은 사건이 지표와 신호에 미치는 영향을 확인한다.
- 신호를 단순 화면 상태로만 표시할지, 알림·기록·성과 분석까지 확장할지 결정한다.

## 7. 책·사용자 연구 메모 추가 양식

책 내용을 전달받으면 원문 전체를 저장하기보다 사용자의 해석, 짧은 출처, 우리 전략에 필요한 변경점을 남긴다. 근거가 확인되지 않은 아이디어는 바로 확정 규칙으로 바꾸지 않는다.

```text
기록일:
책/저자/판/페이지:
핵심 개념(사용자의 말로):
현재 규칙과 충돌하거나 보완되는 점:
제안하는 새 규칙과 예외:
확인할 종목·기간·검증 방법:
결정: 검토 중 / 채택 / 보류 / 철회
코드·테스트 반영 여부:
```

규칙을 바꿀 때에는 이 문서의 현재 규칙·결정 이력·테스트를 함께 갱신한다. 전략 문서의 수정만으로 배포된 홈페이지가 자동 변경되지는 않는다.
